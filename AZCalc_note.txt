エラー表現を型で表す
現状の "-0" 文字列番兵から Double 同様に .nan/.infinity を表現できる内部状態を持たせ、isNaN で判定

RoundType の意味の明確化
case truncateToDigits  // decimalDigits で切り捨て（C層 case 6）
case keepFull          // 丸めず全桁保持（現 .truncate）

演算子の拡充
AZDecimal: power(_:Int)（整数べき乗、二乗法で BCD 厳密）、remainder(dividingBy:)（剰余）、integerValue（整数判定ヘルパー）
AZFormula: ^（べき乗、右結合）トークン追加。% は既にパーセントなので剰余の演算子は追加しない

Codable 準拠：AZDecimal を value 文字列1本で符号化

エラー診断の細分化
AZFormulaError に .unmatchedParenthesis（括弧不一致）と .missingOperand（オペランド不足）を追加

パーセント記号・除数を percentDivisors で公開・設定可能にした

Localizable.xcstrings（デモアプリ）に追加した新キーをローカライズ対応して
エラー: formula.error.overflow / formula.error.unmatchedParenthesis / formula.error.missingOperand（必要なら formula.error.zeroDivision）
丸めモード: rounding.mode.truncateToDigits.* / rounding.mode.keepFull.* / rounding.keepFull.footer
